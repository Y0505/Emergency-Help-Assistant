# Incident image placeholders

Place one image per incident in this folder. The home-page cards already point to these filenames:

- `adult-choking.jpg`
- `severe-bleeding.jpg`
- `unresponsive-cpr.jpg`
- `possible-stroke.jpg`
- `burns.jpg`
- `seizure.jpg`
- `severe-allergic-reaction.jpg`
- `fracture.jpg`

Use original illustrations or images you have permission to use. Keep the main action easy to understand at a glance. The card crops images to fit a landscape frame, so a landscape image around 4:3 or 16:9 works well.

Do not use an image as a substitute for clinically reviewed instructions. Check every image and all related first-aid content with a qualified UK clinical reviewer before public or real-world use.
