# Emergency Help Assistant

**When every second matters.**

An independent, visual-first first-aid demonstration designed to help people find a relevant emergency topic and follow short illustrated guidance while contacting emergency services.

> **Important:** This is an educational demonstration prototype, not a clinically validated medical device or a substitute for emergency services, professional medical advice, or certified first-aid training. All content requires review by a qualified UK first-aid or clinical professional before public use.

## Experience
- Emergency call action (999, with 112 as an alternative) is the first prominent action on the home screen.
- Eight incident categories: choking, severe bleeding, unresponsiveness / CPR, possible stroke, burns, seizure, severe allergic reaction, and suspected fracture.
- Short step-by-step prototype guidance; the original four topics have the more developed decision flows, while the additional topics are concise starter guides requiring clinical review.
- Dedicated replaceable image slots on every incident card. See `assets/images/README.md` for the expected filenames.
- Responsive, phone-first interface.
- Original hand-authored SVG illustrations in the existing guide steps.
- No accounts, patient data collection, or backend.

## Run locally
Open index.html in a modern browser, or serve this folder with any static file server.

## Technology
HTML5, CSS3, vanilla JavaScript, and original inline SVG. No JavaScript or CSS framework dependencies. Typography uses system font stacks; no external font service is required.

## Medical content
The initial wording is a simplified paraphrase informed by the official references in SOURCES.md. Some of the newer incident guides are intentionally brief starter content and are not complete clinical protocols. Medical instructions, branching, age scope, imagery, accessibility, and regional emergency details must be reviewed and tested by qualified professionals before deployment.

This prototype is UK-oriented. Emergency numbers and first-aid protocols vary by country.

## Originality
The interface composition, HTML, CSS, JavaScript, and SVG illustrations were created specifically for this project. No third-party UI framework, icon pack, downloaded stock image, or copied template is used. The general subject of first-aid guidance is not claimed as a novel or exclusive idea.

## Status
Visual refresh in progress — still an independent prototype, not clinically reviewed or production ready.
